了解 DaoKits 的功能特性、使用方法和常见问题。

简介

DaoKits 是一款化繁为简的一站式集成工具箱，硬件检测与实用工具集于一身，即开即用，持续进化。软件采用模块化设计，功能持续扩展，满足多样化的使用需求。

核心特性：

  • 全面硬件检测，厂商名称自动转中文
  • 系统性能优化，深度释放硬件潜力
  • 模块化工具集成，功能持续扩展
  • GitHub + Gitee 双平台智能更新
  • 现代化简洁界面，上手即用
  • 全本地运行，数据不上传，隐私安全

安装与运行

系统要求

  • 操作系统：Windows 10 / Windows 11（64 位）
  • 运行环境：WebView2 Runtime（Win10/11 通常已预装）
  • 网络：可选（仅用于自动更新检测与下载）
  • 权限：普通用户即可运行，完整硬件信息建议管理员权限

运行方式

下载安装程序 installer.exe，双击运行后选择安装位置（或使用默认路径），安装程序会自动下载最新版本并完成安装，同时在桌面创建快捷方式。安装完成后双击桌面快捷方式即可启动。

提示：建议安装到非系统目录（如 D:\DaoKits），以避免权限问题。

快速上手

第一步：安装软件

下载 installer.exe 安装程序，双击运行，选择安装位置后等待自动下载并安装完成。

第二步：启动软件

安装完成后，双击桌面快捷方式启动 DaoKits。软件启动时会自动检测硬件信息并显示「电脑信息」页面。

第三步：浏览功能

通过左侧导航栏切换不同功能页面：

  • 电脑信息：查看硬件与系统详细信息
  • 关于软件：查看版本信息、检查更新

第四步：保持更新

软件启动时会自动检测新版本，如有更新会在导航栏提示，点击「立即更新」即可一键升级。

电脑信息

电脑信息页面展示以下内容：

  • 系统信息：操作系统名称、版本号、位数、安装日期
  • CPU：处理器型号、核心线程数、标称频率、虚拟化状态
  • 内存：总容量、类型（DDR4/DDR5）、频率、通道数、插槽数
  • 显卡：显卡型号、显存容量、驱动版本
  • 主板与 BIOS：主板厂商（中文）、型号、BIOS 版本
  • 磁盘：磁盘品牌（中文）、型号、容量、健康状态、寿命剩余
  • 网络：网卡型号（中文）、MAC 地址、连接状态

自动更新

DaoKits 支持双平台自动更新：

  1. 软件启动时自动检测 GitHub 和 Gitee 两个平台的最新版本
  2. 取两个平台中较新的版本作为最新版本
  3. 如有新版本，导航栏「关于软件」按钮显示更新提示
  4. 点击「立即更新」启动更新程序
  5. 更新程序自动选择最快下载线路，下载并解压更新
注意：更新前请保存好正在进行的工作，更新过程中软件会自动关闭并重启。

关于软件

「关于软件」页面显示：

  • 软件版本号
  • 更新时间
  • 作者信息（Daomak）
  • 官方网站链接
  • 检查更新 / 立即更新按钮

卸载说明

由于 DaoKits 是绿色软件，卸载非常简单：

  1. 关闭正在运行的 DaoKits
  2. 直接删除整个 DaoKits 文件夹即可
  3. 也可以运行文件夹中的 uninstaller.exe 进行卸载

软件不会在系统中留下注册表项或其他残留文件。

常见问题

Q: 软件无法启动怎么办？

A: 请确保操作系统为 Windows 10 或更高版本的 64 位系统。如果被杀毒软件拦截，请添加信任或关闭实时防护后重试。

Q: 硬件信息显示不全？

A: 部分硬件信息需要管理员权限才能读取，请右键以管理员身份运行。

Q: 更新失败怎么办？

A: 可以手动到下载页面下载最新版本，覆盖解压到原目录即可。

Q: 软件会上传我的硬件信息吗？

A: 不会。所有硬件检测均在本地完成，数据不上传任何服务器，保护您的隐私安全。
