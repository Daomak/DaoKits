常见问题

软件无法启动怎么办？
请确保操作系统为 Windows 10 或更高版本的 64 位系统。如果被杀毒软件拦截，请添加信任或关闭实时防护后重试。也可以尝试右键以管理员身份运行。
硬件信息显示不全或不准确？
部分硬件信息需要管理员权限才能读取，请右键以管理员身份运行。如果仍有问题，请在 GitHub 提交 Issue 并附上您的硬件配置信息，我们会尽快修复。
更新失败怎么办？
可以手动到下载页面下载最新版本，覆盖解压到原目录即可。如果自动更新持续失败，请检查网络连接，或尝试切换下载线路（GitHub / Gitee）。
软件会上传我的硬件信息吗？
不会。所有硬件检测均在本地完成，数据不上传任何服务器。软件仅在检查更新时连接 GitHub/Gitee 获取版本信息，不收集任何用户数据。
如何完全卸载软件？
由于 DaoKits 是绿色软件，直接删除整个软件文件夹即可完全卸载，不会在系统中留下注册表项或其他残留文件。也可以运行文件夹中的 uninstaller.exe 进行卸载。
支持哪些操作系统？
目前支持 Windows 10 和 Windows 11 的 64 位系统。暂不支持 32 位系统和 macOS/Linux 系统。
