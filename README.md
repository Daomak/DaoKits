# DaoKits

一站式集成工具箱 —— 面向 Windows 的本地系统与硬件信息查看工具。

打开即看：操作系统、主板、处理器、内存、显卡、硬盘、网卡、声卡、显示器、电源和 USB 设备，全部信息在本机读取，除「检查更新」外不产生任何网络请求，不写注册表、不写系统目录，整个程序目录可拷贝到任意位置直接运行。

技术栈 **Rust + Tauri 2 + 原生 TypeScript**，复用系统 WebView2，免安装单文件约 **2.7 MB**，一次硬件采集耗时 **3–11 ms**。

## 功能

### 首页 · 系统与硬件配置

十一张卡片，覆盖一台机器的软硬件全貌：

| 卡片 | 展示内容 |
|---|---|
| 系统信息 | 操作系统（含中文版本名）、版本、内部版本、内核版本、架构、计算机名、已运行时长、虚拟化状态 |
| 主板 | 品牌 + 型号、BIOS 日期 |
| CPU | 型号、核心数 / 线程数、主频、L2 + L3 缓存合计 |
| 内存 | 品牌 + 代数 + 总容量、条数与频率 |
| 显卡 | 型号、显存容量 |
| 硬盘 | 物理磁盘品牌 + 型号、容量 |
| 网络适配器 | 品牌中文化的网卡名称（虚拟网卡已滤除） |
| 声卡 | HDMI 音频、板载声卡芯片、USB 音频设备 |
| 显示器 | 型号、分辨率与刷新率（读 EDID + 当前显示模式） |
| 电源 | 交流 / 电池供电方式、电池状态 |
| USB 设备 | 当前连接的外设清单 |

### 关于 · 版本与更新

版本信息、官网与联系方式，以及内置的在线更新：启动时静默比对 GitHub Releases 的版本号，发现新版本可一键下载、解压并自动重启。

## 下载

到 [Releases](https://github.com/Daomak/DaoKits/releases) 下载最新版本：

- **安装版**：`DaoKits_x.y.z_x64-setup.exe`，自动创建开始菜单项与卸载入口，按当前用户安装，无需管理员权限
- **免安装版**：下载 zip 解压后直接运行 `DaoKits.exe`

两种方式都支持在线更新。

## 设计原则

- **体积优先**：Rust 侧 `opt-level="z"` + LTO + 单 codegen unit + `strip`；前端不使用任何框架，产物个位数 KB
- **高效稳定**：静态硬件信息优先走注册表与 Win32 API，避开采样型接口（`sysinfo::System::new_all()` 单次 380 ms 以上，会明显拖慢首屏）
- **零依赖采集**：固件表（SMBIOS）、磁盘 IOCTL、EDID、电源状态全部直接调系统 API，不引入额外 crate
- **绿色便携**：所有运行时路径基于 exe 所在目录，不写注册表、不写 `%APPDATA%`
- **不联网**：除用户主动或启动时自动检查更新外，程序不发起任何网络请求，不上报任何数据

## 从源码构建

### 环境要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| Node.js | ≥ 18 | 构建前端资源 |
| Rust | stable MSVC | 通过 rustup 安装 |
| MSVC 生成工具 | VS 2022 Build Tools | 需含 `VC.Tools.x86.x64` 与 Windows SDK |
| WebView2 | 任意 | Windows 10 1803+ / Windows 11 自带 |

### 命令

```powershell
npm install      # 首次安装前端依赖
npm run app      # 开发模式（热重载）
npm run dist     # 打包，产物在 src-tauri/target/release/ 与 bundle/nsis/
```

### 运行时目录

```
DaoKits.exe
├── data/          # 应用数据
└── logs/
    └── app.log    # 超过 2 MB 自动滚动为 app.log.1
```

## 已知限制

- 无盘工作站（iCafe8、网众一类的虚拟盘系统）里，硬盘卡显示的是虚拟磁盘，不是物理型号
- 部分机型需要更高权限才能读到磁盘型号，普通权限下可能显示为空
- 内存频率取的是当前运行频率，不是模组的 XMP / EXPO 标称频率
